## 폴더는 이렇게 사용합니다

```text
soxl-short-hit/
├── README.md                    ← 전체 사용 설명
├── records/                     ← 매매 기록과 영상 준비
│   ├── TEMPLATE.md              ← 다음 날 복사할 빈 양식
│   └── 2026-10-21/
│       ├── trade.md             ← 주문·결과·마감 잔액
│       ├── order.json           ← 주문·체결 결과·잔액 데이터
│       ├── morning-review.md    ← 미국장 결과 확인
│       └── shorts-draft.md      ← 영상 제목·내레이션·자막
└── news/                        ← 관련 뉴스
    ├── TEMPLATE.md              ← 다음 뉴스 정리용 빈 양식
    └── 2026-10-21/
        ├── briefing.md          ← 읽기 쉬운 뉴스 요약
        └── sources.csv          ← 출처 목록
```

`.md`는 읽고 수정하는 글 파일입니다. `.csv`는 엑셀 등에서 표로 열 수 있습니다.
`.json`은 나중에 기록을 자동으로 모으기 위한 데이터 파일입니다.

## 매일 할 일

1. **주문할 때:** `records/날짜/` 폴더를 만들고 [매매 양식](records/TEMPLATE.md)을 `trade.md`로 복사합니다. 잔고, 주문 가격, 수량을 적습니다.
2. **뉴스를 모을 때:** `news/같은 날짜/` 폴더를 만들고 [뉴스 양식](news/TEMPLATE.md)을 `briefing.md`로 복사합니다. 확인 시각과 출처를 함께 적습니다.
3. **아침에:** 증권사 거래 내역을 보고 체결 여부, 실제 수량, 실제 가격, 수수료를 입력합니다. 오늘의 미국장 미체결 결과는 사용자 설명을 바탕으로 반영했습니다.
4. **영상 준비:** 확인된 결과를 대본에 넣습니다. 체결 전에는 “매수 주문”, 체결 확인 후에는 실제 체결 수량과 가격을 말합니다.

폴더 이름은 **한국에서 일지를 정리한 날짜**입니다. 최초 기록의 기준 시각은 한국시간 **2026-10-21 00:40:44**, 같은 순간 뉴욕은 **2026-10-20 11:40:44 EDT**입니다. 실제 주문 시각은 아직 알려지지 않았으므로 별도 확인란에 남겼습니다.

`order.json`은 원래 주문 가격·수량과 시작 잔고를 보존하고, 미국장 결과와 한국장 마감 잔액을 별도 항목으로 저장합니다. `null`은 **아직 모르는 값**이며 0이라는 뜻이 아닙니다. 추가 거래 내역 미제공과 미국장 체결 0주를 구분합니다.

한국장 시간대의 종목·매수/매도 가격·수량·수수료·입출금·마감 보유량이 확인되면 개별 거래와 실현손익을 추가할 수 있습니다.
현재는 파일에 직접 기록하는 방식이며, 영상 대본은 초안 상태입니다.
