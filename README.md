## 먼저 열어볼 파일

- [오늘의 매매 기록](records/2026-10-21/trade.md): 잔고와 주문 내용
- [아침 확인표](records/2026-10-21/morning-review.md): 체결 수량·가격·수수료를 적는 곳
- [Shorts 대본 초안](records/2026-10-21/shorts-draft.md): 현재 확인된 내용으로 만든 영상용 문장
- [SOXL 관련 뉴스](news/2026-10-21/briefing.md): 뉴스 5건, 실적 설명회 일정 2건, 공식 상품 설명
- [뉴스 출처 목록](news/2026-10-21/sources.csv): 발표일·사건일·원문 링크

## 폴더는 이렇게 사용합니다

```text
soxl-short-hit/
├── README.md                    ← 전체 사용 설명
├── records/                     ← 매매 기록과 영상 준비
│   ├── TEMPLATE.md              ← 다음 날 복사할 빈 양식
│   └── 2026-10-21/
│       ├── trade.md             ← 주문할 때 기록
│       ├── order.json           ← 같은 주문을 데이터로 저장
│       ├── morning-review.md    ← 아침에 결과 입력
│       └── shorts-draft.md      ← 영상 제목·내레이션·자막
└── news/                        ← 관련 뉴스
    ├── TEMPLATE.md              ← 다음 뉴스 정리용 빈 양식
    └── 2026-10-21/
        ├── briefing.md          ← 읽기 쉬운 뉴스 요약
        └── sources.csv          ← 출처 목록
```

`.md`는 읽고 수정하는 글 파일입니다. `.csv`는 엑셀 등에서 표로 열 수 있습니다.
`.json`은 나중에 기록을 자동으로 모으기 위한 데이터 파일입니다.

## 매일 할 일

1. **주문할 때:** `records/날짜/` 폴더를 만들고 [매매 양식](records/TEMPLATE.md)을 `trade.md`로 복사합니다. 잔고, 주문 가격, 수량을 적습니다.
2. **뉴스를 모을 때:** `news/같은 날짜/` 폴더를 만들고 [뉴스 양식](news/TEMPLATE.md)을 `briefing.md`로 복사합니다. 확인 시각과 출처를 함께 적습니다.
3. **아침에:** 증권사 거래 내역을 보고 체결 여부, 실제 수량, 실제 가격, 수수료를 입력합니다. 오늘은 준비된 `morning-review.md`를 채우면 됩니다.
4. **영상 준비:** 확인된 결과를 대본에 넣습니다. 체결 전에는 “매수 주문”, 체결 확인 후에는 실제 체결 수량과 가격을 말합니다.

폴더 이름은 **한국에서 일지를 정리한 날짜**입니다. 이번 기록의 기준 시각은 한국시간 **2026-10-21 00:40:44**, 같은 순간 뉴욕은 **2026-10-20 11:40:44 EDT**입니다. 실제 주문 시각은 아직 알려지지 않았으므로 별도 확인란에 남겼습니다.

## 아침에 이어서 작성할 때

`records/2026-10-21/morning-review.md`에 결과를 적은 뒤, `order.json`에도 실제 체결 정보를 반영합니다. `null`은 **아직 모르는 값**이며 0이라는 뜻이 아닙니다. 원래 주문 가격·수량은 보존합니다.

그다음 `shorts-draft.md`의 마지막 부분을 실제 결과로 바꾸면 됩니다.
현재는 파일에 직접 기록하는 방식이며, 영상 대본은 초안 상태입니다.
