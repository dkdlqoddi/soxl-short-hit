볼트용 전체 노트는 `automation/runs/20261106-094235/vault-fallback/soxl-review-codex.md`에 저장했다. 목표 경로는 `PERSONAL/STOCK/SOXL/2026-11-05-review-codex-astra-max.md`이며 `vault_written: false`다. 본인 이전 볼트 갱신 후보는 `research/2026-11-06/soxl-data/codex/own_forecast_vault_updated.md`, 변경할 6절은 `own_forecast_review_section.md`에 있다. **연결 복구 후 현재 본문·version을 읽고, 원래 본문을 보존하며 6절·status만 반영한 뒤 그 version을 ifMatch로 전달하고 재읽어야 한다.** 후보 파일을 읽지 않은 기존 볼트에 무조건 덮어쓰라는 의미가 아니다.

### 5.2 데이터 품질·재현 자료

- 미국 15개 티커의 5일 1분봉과 1개월 일봉을 **09:44:06~09:44:08 KST / 11/5 19:44:06~19:44:08 EST**에 Yahoo Chart API에서 직접 수집했다. 11월 4·5일 SOXL 정규장 분봉은 각각 **390개**였고, 만기 평가에 사용한 두 봉은 거래량이 양수다. 원시 응답·CSV·URL·조회 시각·SHA256을 저장했다.
- **시간외 거래량 0**은 공급 필드의 한계일 수 있어 무체결 증거로 단정하지 않았다. 11월 5일 **23:15~23:29 KST / 09:15~09:29 EST** 분봉 15개는 조회 응답에 없다. 프리마켓 마지막 확인값은 23:14 / 09:14로 적고 빈 구간을 보간하지 않았다. 공통 만기의 개장 봉은 존재한다.
- 별도 Yahoo 호스트 재조회에서도 만기 Open과 Codex 대용 Close가 일치했다. 이는 같은 공급원의 전송 일관성 확인이지 독립적인 거래소 교차 검증은 아니다. Stock Analysis에서 $56.95 개장가와 $73.12 이전 종가를 추가 확인했다. Nasdaq API는 요청 종료일이 11월 5일이어도 실제 응답은 **11월 4일까지**였으므로 11월 5일 가격 확인 근거로 쓰지 않았다.
- 만기 후 11월 5일 미국장 종가는 Yahoo $40.87 / Stock Analysis $40.92 / 마지막 15:59 분봉 종가 $40.90으로 다르다. 이 차이를 공개하며, 평가 대상인 $56.95 및 $51.17을 그 종가로 교체하지 않았다.
- 한국 일봉 조회는 **11월 6일 09:46경 KST / 11월 5일 19:46경 EST**에 수행했으며 정확한 시각은 `source_access.json`에 있다. 삼성전자·SK하이닉스는 **11월 5일 확정 일봉**만 사용했고 11월 6일 장중값은 분석에서 제외했다. KOSPI 11월 5일 Yahoo 일봉은 결측이라 코스피 종가는 **09:49:46 KST / 19:49:46 EST**에 재조회한 헤럴드경제 본문으로 확인했다.
- 뉴스·공시 확인 시각은 09:44~09:50 KST / 11월 5일 19:44~19:50 EST다. 일부 사이트는 일반 HTTP 요청에서 403이었지만 브라우징 도구에서 공식 본문을 확인했다. `source_access.json`의 HTTP 상태와 브라우징 확인을 구별한다.

모든 데이터·스크립트는 `research/2026-11-06/soxl-data/codex/`에 둔다. 핵심 파일은 `collection_manifest.json`, `source_access.json`, `web_crosscheck.json`, `review_metrics.json`, `SOXL_15m_confirmations.csv`, `original_forecast_*.md`, `vault_access.json`, `vault_sync_pending.json`이다. 이번 시세 원본을 교체하지 않고 계산만 재현하려면 저장소 루트에서 다음을 실행한다.

```bash
python3 research/2026-11-06/soxl-data/codex/analyze_review.py
python3 research/2026-11-06/soxl-data/codex/plot_review.py
```

`collect_review.py`·`crosscheck_sources.py`는 온라인 재수집으로 원본 파일을 교체하므로 이번 복기 재현에는 재실행하지 않는다. 새 백테스트·최적화·검증되지 않은 체결 시뮬레이션을 추가하지 않았다.
